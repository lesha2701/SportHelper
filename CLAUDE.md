# Правила работы в этом репозитории

- Общение с владельцем — **по-русски**. Планы и итоги коротко, по пунктам.
- **Не делать `git push`, не публиковать сборки (TestFlight/App Store) без явного разрешения** владельца в этом же сообщении.
  Коммитить локально, затем спросить.
- **Секреты** (ключи, пароли, токены, сертификаты, `.p8`/`.p12`, `Secrets.xcconfig`) не коммитить и не выводить в чат.
- **Реальных платежей не делать**: оплату проверять только на тестовом сервере с имитацией ЮKassa.
- Контракт сервера менять нельзя, он в другом репозитории. Если API неудобен или чего-то нет — составить короткий запрос
  владельцу (список «чего на сервере ещё нет» — в `docs/BRIEF.md`, раздел 7).
- Начинать работу с `docs/BRIEF.md` (полное задание, этапы, требования App Store).
- Сетевой слой и модели — в `SportArenaKit`, покрывать тестами (`swift test` работает без Xcode). Экраны — в приложении.
- Интерфейс на русском, светлая и тёмная темы, строки в `Localizable.xcstrings`.
