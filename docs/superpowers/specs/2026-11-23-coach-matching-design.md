# Подбор тренера — проект

Утверждён владельцем 23.11.2026 (в чате: «в целом совсем согласен… можно начинать реализацию»).

## Зачем
Спортсмен не всегда находит нужного тренера в каталоге. Мы берём подбор на себя: человек заполняет анкету, администраторы выбирают
подходящих тренеров среди тех, кто согласился на подбор, тренер соглашается, спортсмен соглашается, оплачивает — и только после
оплаты они получают контакты. За первую тренировку с таким клиентом платформа берёт повышенную комиссию (по умолчанию 50%),
потому что клиента привели мы.

## Цели
- Анкета «Подобрать тренера» на вкладке «Тренеры» (сайт, iPhone): много необязательных полей, обязателен только вид спорта.
- Очередь заявок в админке со всей информацией.
- Тренер включает «меня можно рекомендовать» и видит условия: первая тренировка с клиентом из подбора — повышенная комиссия и почему.
- Повышенная комиссия за первую тренировку настраивается в админке (по умолчанию и на конкретное предложение), с историей.
- Контакты открываются только после оплаты.

## Не цели / анти-цели
- Не собираем возраст и другие данные, которых сейчас нет в платформе (среди клиентов могут быть дети). Анкета содержит только то, что уже
  есть или спрашивается без проблем: вид спорта, цель, уровень, формат, город, бюджет, когда удобно, комментарий.
- Платформа не должна терять комиссию на обходе: до оплаты тренер видит анкету без имени и контактов.
- Не меняем цену для спортсмена: повышенная комиссия удерживается из доли тренера.

## Решения (по обсуждению)
1. Обход платформы: обезличенная анкета до принятия; контакты и чат записи из подбора — после оплаты; для таких записей оплата
   в приложении обязательна.
2. «Первая тренировка»: повышенный процент применяется к одной записи — первой оплаченной после принятия предложения. Если она
   отменена/полностью возвращена, право переходит к следующей записи. Состоялась и оплачена — право использовано.
3. Атрибуция: связь «спортсмен + тренер» действует N дней (по умолчанию 30) после принятия; первая запись в это окно идёт по правилам
   подбора, даже если спортсмен пришёл из каталога. Нельзя предлагать тренеру человека, который уже у него занимался или состоит в его
   команде, и пару, где есть блокировка.
4. Согласие тренера: процент фиксируется в самом предложении (как в платежах); новая редакция оферты тренера и запись согласия.
5. Формулировка для спортсмена: «подобрали из тренеров, участвующих в подборе», без «лучший из всех».
6. Предложение имеет статусы и сроки (тренер не ответил, спортсмен не ответил, никто не подошёл). Предлагать можно нескольким
   тренерам сразу: кто принял первым — тот; остальным предложение закрывается.
7. Повышенный процент заменяет личный и общий для одной записи; у него свой верхний предел; свой журнал изменений.
8. Заявку может подать только вошедший человек; ограничение по частоте и по числу открытых заявок.

## Этапы
1. **Анкета и очередь заявок** (этот PR): таблица заявок, API автора и админов, форма на сайте и в iPhone, раздел админки.
2. Согласие тренера на подбор, предложения тренерам, их ответ, согласие спортсмена.
3. Повышенная комиссия за первую тренировку, обязательная оплата и открытие контактов, проверки на деньги.

Android (`mobile/`) ведёт второй разработчик; ему передаётся описание API каждого этапа.

## Остаётся на исполнителя
Точные тексты, раскладка экранов, имена полей, сроки по умолчанию (30 дней окно атрибуции; 48 ч на ответ тренера) — их можно менять в
настройках без новой версии приложения.

## Этап 2: согласие тренера, предложения, ответы (решения исполнителя)
Эти решения принял исполнитель в рамках общего утверждённого проекта; их можно менять.
- **Согласие тренера.** В профиле тренера переключатель «Подбор клиентов». Включить можно, только приняв текущую редакцию условий
  (версия и дата сохраняются). Условия показывают процент первой тренировки, причину («клиента привели мы»), что это разово, что
  каждое предложение можно отклонить и что имя и контакты спортсмена открываются только после его выбора и оплаты первой тренировки.
  Новая редакция условий отключает подбор у тех, кто не принял её заново.
- **Предложение** (`coach_match_offers`): заявка + тренер, статусы `proposed → coach_accepted | coach_declined`, затем
  `athlete_accepted | athlete_declined`, либо `withdrawn`. Процент первой тренировки и версия условий фиксируются в предложении.
  Сроки: тренер отвечает 48 ч, спортсмен — 72 ч; просрочка вычисляется на лету (фоновая задача не нужна).
- **Кому можно предложить.** Тренер включил подбор и принял условия; не автор заявки; есть опубликованное и не скрытое модерацией
  объявление; нет блокировки в любую сторону; нет «живой» связи (бронь или команда, где этот тренер ведёт спортсмена).
  На одну заявку — не больше 5 активных предложений. Первый принявший тренер выигрывает: остальные предложения отзываются.
- **Что видит тренер.** Обезличенную анкету: вид спорта, цель, уровень, формат, город, бюджет, время, комментарий. Без имени и
  контактов; в свободном тексте телефоны, почты, ссылки и @ники заменяются на «[контакт скрыт]».
- **Что видит спортсмен.** Только тех тренеров, кто принял предложение: карточка тренера и его объявления; выбрать или отказаться.
  После выбора заявка становится «подобрана» и спортсмен записывается на тренировку обычным путём; повышенный процент,
  обязательная оплата и открытие контактов — этап 3.
- **Уведомления.** Тренеру: новое предложение (`match_offer`); спортсмену: тренер согласился (`match_offer_reply`). Оба — служебные,
  без переключателя.
- **Настройки.** `MATCH_FIRST_SESSION_COMMISSION_PERCENT` (50), `MATCH_COACH_REPLY_HOURS` (48), `MATCH_ATHLETE_REPLY_HOURS` (72).

## Этап 3: повышенная комиссия, обязательная оплата, контакты после оплаты (решения исполнителя)
- **Процент.** Общий процент первой тренировки хранится с журналом изменений (таблица `match_commission_changes`, как у общей
  комиссии; пока записей нет — берётся `MATCH_FIRST_SESSION_COMMISSION_PERCENT`). Менять может только финансовый администратор
  с недавним подтверждением входа; изменение пишется в журнал аудита. При создании предложения процент копируется в него;
  финансовый администратор может задать свой процент на конкретное предложение (нужна причина, пишется в аудит).
- **Окно атрибуции.** `MATCH_ATTRIBUTION_DAYS` (30) считается от ответа спортсмена «выбираю». Запись, созданная спортсменом этому
  тренеру внутри окна (с любого объявления тренера, в том числе из каталога), попадает под правила подбора.
- **Право на повышенный процент** — у одной «живой» записи: ожидает ответа тренера, подтверждена (и не просрочена без оплаты) или
  оплачена. Если запись отклонена, истекла, отменена или полностью возвращена, право переходит к следующей записи.
  Бесплатные записи (цена 0) право не занимают. Привязка фиксируется в `bookings.match_offer_id` при создании записи под блокировкой
  предложения, поэтому две одновременные записи не получат повышенный процент обе.
- **Оплата.** Процент берётся из предложения при старте оплаты и замораживается в платеже. Для записи из подбора оплата в
  приложении обязательна: предложение нельзя создать, пока платежи выключены или у тренера нет объявления с ценой; тренер не может
  отметить такую запись состоявшейся без оплаты.
- **Контакты.** Пока запись из подбора не оплачена, тренер видит её без имени («Спортсмен из подбора»), не может открыть профиль
  и отзывы спортсмена; в уведомлениях имя скрыто. Чат открывается только после оплаты (уже так устроено). После оплаты всё открывается.
- **Обход через вторую запись.** Пока у спортсмена есть «живая» неоплаченная запись, которой достался повышенный процент, новую запись к этому
  тренеру создать нельзя (409): иначе обычная запись, оплаченная по обычной комиссии, открыла бы чат и контакты. Имя скрыто, пока у пары есть
  запись из подбора, которая ещё в игре (окно открыто или запись жива), и ни одна запись из подбора не оплачена.
