# Чаты

Два вида чата: **личной тренировки** (игрок ↔ тренер) и **команды** (все участники). Только текст, фото и видео.

## Кто и когда может писать

| Чат | Кто | Когда открывается | Когда закрывается для новых сообщений |
|---|---|---|---|
| Личной тренировки (по брони) | игрок и тренер этой брони | бронь подтверждена тренером **и оплачена** (или бесплатная) | оплата возвращена / бронь больше не подтверждена; история остаётся доступной для чтения |
| Команды | все **текущие** участники команды | сразу, при первом открытии | вышел или удалён из команды — доступ пропадает сразу (в том числе к фото и видео из чата) |

Участники в чате не хранятся: доступ вычисляется по брони или составу команды при каждом запросе. Посторонний на любой запрос по чужому
чату получает «не найдено», так что даже о существовании чата узнать нельзя. Войти нужно с обычной сессией, изменяющие запросы
проверяют CSRF-токен, как и везде.

Кнопка «Чат с тренером» / «Чат с игроком» — на карточке брони («Профиль → Мои брони» у игрока, «Профиль → Записи» у тренера), только
когда чат действительно открыт. Чат команды — вкладка «Чат» на экране команды. Значок на кнопке и вкладке — число непрочитанных.

## Фото и видео

Вложения проходят через **те же обработчики, что и все остальные фото и видео сайта**, поэтому правила одинаковы:
фото — JPEG, PNG, WebP, GIF, проверка по содержимому, поворот по EXIF, уменьшение до 1600 px, WebP, удаление метаданных, миниатюра
(см. [images.md](images.md)); видео — MP4, MOV, WEBM, не больше `MAX_VIDEO_SIZE_MB` и `MAX_VIDEO_DURATION_SECONDS` (проверка ffprobe до
отправки на Яндекс Диск). Любые другие файлы отклоняются (415). Файл отдаётся только участникам чата (`access_level = CHAT`), никогда
публично, и пропадает вместе с удалённым сообщением.

## Как это работает

* Новые сообщения страница запрашивает каждые 5 секунд (`GET /api/chats/{id}/messages?after_id=N`), только пока вкладка открыта.
  Постоянного соединения нет (оно не нужно за прокси Caddy и не усложняет развёртывание).
* Сообщение отправляется с `client_key`: повторная отправка (двойной клик, повтор после обрыва) создаёт **одно** сообщение; повторная
  загрузка файла не сохраняет его второй раз.
* Текст — только простой текст до 2000 символов (управляющие символы убираются, HTML не интерпретируется).
* Лимиты: 40 сообщений в минуту и 10 вложений за 5 минут на человека (`AUTH_RATE_LIMIT_ENABLED`).
* Удалить можно своё сообщение; в чате команды главный и ассистент тренера могут удалить любое. Удалённое остаётся строкой
  «Сообщение удалено», текст и файл недоступны никому.
* **Уведомления:** одно на человека на «серию непрочитанного» — пока человек не открыл чат, новые сообщения нового уведомления не создают;
  после прочтения следующее сообщение снова уведомит. Категории `chat_booking` и `chat_team` можно отключить в настройках уведомлений
  (колокольчик, Telegram, если подключён). Нажатие открывает нужный чат.

## API (`/api/chats`)

`GET /unread` · `GET /for-booking/{booking_id}` · `GET /for-team/{team_id}` · `GET /{id}` · `GET /{id}/messages?before_id&after_id&limit` ·
`POST /{id}/messages` · `POST /{id}/messages/media` (multipart) · `DELETE /{id}/messages/{message_id}` · `POST /{id}/read`.

## Данные (миграция `0040_chat.sql`)

`chat_conversations` (одна на бронь / команду), `chat_messages` (порядок — `BIGSERIAL`, `client_key` уникален на отправителя и чат),
`chat_reads` (до какого сообщения прочитано). В `files.access_level` добавлено значение `CHAT`, в категории уведомлений — `chat_booking`,
`chat_team`. Миграция только добавляет таблицы и ослабляет два CHECK; перед применением на боевой базе нужна резервная копия, как обычно.

## Известные ограничения

* Нет редактирования сообщений, ответов, реакций, поиска по чату и индикатора «печатает».
* Нет отметок «прочитано» для собеседника: прочитанное видно только самому читателю (счётчики).
* **Нет жалоб на сообщения и просмотра текста чатов в админ-панели.** Удалять сообщения может автор и тренеры команды. **Фото и видео из
  чатов** администратор находит в «Модерация → Чаты», может скрыть или удалить их (сообщение остаётся пометкой «Сообщение удалено»).
  Учтите: это приватная переписка, администратор видит эти файлы только в рамках модерации (действия пишутся в журнал).
* Новый участник команды видит всю прежнюю переписку.
* Чат личной тренировки доступен только после оплаты через сайт: если онлайн-оплата выключена, платные брони чата не получают.
* Если тренер вручную сменил участников команды, непрочитанные сообщения у ушедшего исчезают из счётчика вместе с доступом.
