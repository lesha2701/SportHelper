# SportArenaGlobal для iOS

Нативное приложение (SwiftUI, iOS 17+) для платформы SportArenaGlobal. Сервер и сайт живут в другом репозитории
(`lesha2701/SportHelper`); здесь только iOS. Полное задание — [docs/BRIEF.md](docs/BRIEF.md), контракт сервера —
[docs/openapi-mobile.json](docs/openapi-mobile.json).

## Что уже есть в приложении

- Вход, выход, сессия в Keychain (человек не входит заново при каждом запуске).
- Регистрация, как на сайте: роль (игрок или тренер), имя, почта, пароль (от 12 символов), согласия своей роли со ссылками на документы
  (они открываются на сайте), экран «Проверьте почту» с повторной отправкой письма раз в минуту. Подтверждение происходит по ссылке
  из письма на сайте, после чего человек входит в приложении; неподтверждённая почта при входе объясняется и предлагает письмо ещё раз.
  «Забыли пароль?» — письмо со ссылкой на сайт, ответ сервера одинаков для любого адреса. Редакции документов (`LegalDocument`) совпадают
  с сайтом и сервером: менять только вместе с `frontend/src/legal/documents.ts` и `backend/app/services/legal.py`.
- «Пожаловаться»: на объявление тренера (меню «⋯» в объявлении), на участника команды (свайп или долгое нажатие по строке состава) и
  на автора сообщения чата (долгое нажатие). Причина из пяти, комментарий (для «Другой причины» обязателен); жалобу видят только
  модераторы. Жалоба на отдельное сообщение уходит как жалоба на его автора: сервер принимает жалобы на пользователя, объявление и
  материал. Своё пожаловаться нельзя (кнопки нет).
- Уведомления: лента (колокольчик на «Главной» с числом непрочитанных и пункт в профиле), отметка прочитанным по нажатию и «Прочитать все»,
  переход к тому, о чём уведомление (тренировка, заявки, брони, задания, чаты, форма личной тренировки; денежные только информируют),
  настройки: выключатель на каждый вид (11, денежные без выключателя). Число непрочитанных спрашивается раз в 45 секунд, пока
  приложение открыто (push появится вместе с APNs).
- Отзывы: игрок оценивает тренера после проведённой тренировки (карточка брони и просьба из уведомления сразу открывают форму), тренер
  отмечает «Тренировка проведена» (кнопка с начала занятия) и оставляет отзыв об игроке; звёзды 1–5 (по умолчанию 5) и комментарий до 2000
  знаков; один отзыв на бронь, сервер отказывает во втором. В объявлении тренера — последние отзывы и «Все отзывы» (до 50).
- Чужие профили: страница тренера (из объявления: о себе, достижения, объявления, все отзывы, жалоба) и страница игрока для его тренера
  (из входящих заявок и записей: данные, отзывы тренеров, достижения, жалоба; сервер не показывает её тренеру без общей команды или
  записи). Достижения: фото открываются во весь экран, видео проигрываются, на чужой материал можно пожаловаться.
- Мои объявления (тренер, в профиле): список с состоянием (опубликовано, черновик, скрыто модератором с причиной), создание и правка
  (название, описание, цена, длительность, формат, город, фото, видео до 60 секунд, недельное расписание окнами), удаление (сервер не даёт
  удалить объявление с активной бронью). Сохранение как на сайте: новое объявление создаётся черновиком, получает расписание и файлы и
  публикуется последним шагом; если файл не загрузился, объявление остаётся и повтор меняет его, а не создаёт второе. Валюта всегда рубли.
- Безопасность аккаунта (Профиль → Аккаунт): смена пароля (текущий, новый, повтор; остальные устройства разлогиниваются), смена email (письмо со ссылкой уходит на новый адрес, ссылка открывается на сайте; на старый уходит предупреждение), список устройств с завершением чужих сессий и «Выйти на всех устройствах». У аккаунта без пароля (создан через Telegram) смена скрыта. Приложение называет себя серверу «SportArena iOS <версия>», так оно и видно в списке устройств
- Конфиденциальность (Профиль → Аккаунт): переключатель «AI-анализ для личных тренеров» — разрешить тренеру с подтверждённой личной тренировкой использовать данные игрока для AI-анализа. Выключено по умолчанию; значение берётся с сервера, при отключении сервер удаляет уже подготовленные анализы. Двухфакторной защиты в приложении нет: на сервере и сайте она только для администраторов
- Помощь (Профиль → Аккаунт): справочник «О приложении» как на сайте — что есть в каждом разделе (главная, команды, библиотека, календарь, тренеры, профиль, уведомления, поиск, ИИ, вход); тексты сайта, переписанные под приложение (без Telegram и горячих клавиш, с названиями кнопок приложения); сверху кнопка знакомства с приложением. Тексты лежат в Kit (`HelpGuide`), поэтому их проверяют тесты. Работает без сети
- Занятие тренера на экране тренировки: личная тренировка, на которую тренера записал игрок (из календаря, с главной, из поиска), показывает карточку «Занятие с игроком» — те же действия, что в «Профиль → Записи» и на странице тренировки сайта: «Тренировка проведена» (с начала занятия; после неё сразу предлагается отзыв об игроке), отзыв об игроке, профиль игрока, выбор плана, чат занятия. Бронь берётся запросом по тренировке (`/api/bookings/coach/by-training/{id}`); если брони тренера за тренировкой нет, карточки нет
- Правки по отзывам (понятность экранов): все надписи в кнопках по центру («Профиль игрока», «Чат тренировки»); у полей объявления и задания подписи-подсказки, у «Что игрок должен сдать» значок «?» с пояснением каждого пункта; в недельном расписании объявления у каждого окна кнопка-корзина; вверху «Заданий» команды — «Добавить задание из библиотеки», в форме задания «Назначить» вместо «Дать»; в форме тренировки команды всегда виден раздел «План тренировки» с выбором плана из библиотеки (или подсказкой, где его создать); при создании плана упражнения сразу раскладываются по разминке, основной, игровой части и заминке; в «Упражнениях и планах» команды у тренера кнопка «Открыть команде упражнения/планы» со списком переключателей; повторное нажатие на текущую вкладку возвращает её на первый экран; главная обновляется при возврате на вкладку; тексты «Помощи» с заглавной буквы; у тренера в профиле отдельный блок «Объявления» (мои объявления, финансы, каталог тренеров), а своё объявление он видит и в каталоге с пометкой «Ваше объявление»
- Знакомство с приложением: 11 страниц с теми же словами, что и на сайте (без мест, которые есть только в вебе). Новому человеку показывается само поверх приложения («Пропустить» или «Перейти в приложение» записывает на сервере, что тур пройден — одно на сайт и приложение); из профиля открывается вручную (Профиль → Аккаунт → Знакомство с приложением, с крестиком, ничего не записывает). Листается кнопками и свайпом, на последней странице отмечена роль человека
- Финансы тренера (Профиль → Тренировки → Финансы; только если сервер включил раздел, `trainer_balance`): четыре плитки баланса (доступно к выводу, ожидает проведения занятия, в обработке, выплачено всего), примечание о задолженности, объяснение комиссии, заявки на вывод со статусом и причиной отказа, история операций (кто сколько заплатил, комиссия платформы, статус начисления) по 20 штук с «Показать ещё». Только чтение: заявку на вывод создают на сайте (нужны пароль и реквизиты; реквизиты сервер присылает уже скрытыми). Уведомления о начислении и выплате ведут на этот экран
- Поиск (лупа в верхней панели главной): общий поиск сайта по командам, игрокам своих команд, тренерам, тренировкам, матчам, заданиям и (тренеру) упражнениям, по пять каждого вида; спрашивает сервер через 0,3 с после последней буквы и не спрашивает короче двух символов. Результат открывает свой экран поверх поиска (команда и игрок — команду, как на сайте; матч, задание, тренировка, тренер — свои страницы), упражнение ведёт в «Библиотеку». Лупа только на главной: на остальных вкладках у приложения нет общей верхней панели
- Отчёт о самостоятельной тренировке (в карточке прошедшей тренировки, кнопка «Отчёт»): ответственный игрок пишет текст (до 2000 знаков), после отправки может добавить фото и видео; остальные члены команды читают; тренерский штаб принимает отчёт или возвращает на доработку с комментарием. Повторная отправка снова ставит отчёт «На проверке»
- Профиль: просмотр, правка, аватар, удаление аккаунта.
- Календарь: список, неделя, экран тренировки.
- Тренеры: каталог с фильтрами, страница объявления, запись на тренировку.
- Брони и оплата: «Мои брони», оплата через страницу ЮKassa (сумму считает и отдаёт сервер, приложение её не присылает),
  проверка статуса у сервера после закрытия страницы; для тренера — входящие заявки и записи.
- Чаты: чат личной тренировки и чат команды (текст, фото; видео можно смотреть), повтор неотправленных сообщений,
  счётчики непрочитанного на вкладках.
- Команды: список, карточка (состав, чат), создание и правка (тренер), приглашение ссылкой, заявки на вступление,
  вступление по приглашению, выход.
- Тренировки команды: список (предстоящие, прошедшие), для тренерского состава — назначить (в том числе серию на каждую неделю,
  самостоятельную тренировку с ответственным игроком), изменить, отметить проведённой, отменить, отменить серию, удалить.
- Задания команды: тренерский состав даёт задание всей команде, выбранным игрокам или игрокам одной позиции (срок, показатель,
  что сдать: комментарий, фото, подходы и повторы, длительность, результат, сложность, самочувствие), меняет и удаляет его, видит
  выполнение каждого и принимает работу или отправляет на доработку с комментарием. Игрок видит свои задания (в карточке команды и в
  «Профиль → Мои задания»), начинает и сдаёт их, в том числе повторно после доработки.
- Матчи команды: расписание (предстоящие, сыгранные), для тренерского состава — добавить, изменить, назвать состав, внести счёт,
  удалить; игрок видит матчи, состав и счёт.
- Главная: ближайшее событие, показатели и задания игрока; у тренера — показатели выбранной команды (посещаемость, нагрузка, кому нужно
  внимание, последние матчи) и быстрые действия (тренировка, задание, матч).
- «Эта неделя» на главной (у игрока и тренера): полоса из семи дней с понедельника, у дней с событиями точка; нажатие на день показывает его события (по умолчанию сегодня), отменённые не считаются в количестве. Главная теперь загружает события с понедельника текущей недели
- Личные тренировки: «+» в Календаре и «Запланировать личную тренировку» на Главной у игрока. Дата, время, длительность, место,
  напоминание, повтор по неделям; упражнения «на повторения» (повторения, время или расстояние — тип подсказывается по названию) или
  «круговая» (круги и отдых) записываются в описание так же, как на сайте; можно попросить ИИ предложить тренировку. Свою личную
  тренировку можно изменить, отметить проведённой или отменённой, отменить серию и удалить. Проведение по шагам («Начать тренировку» в
  своей личной тренировке, упражнения которой записаны списком): по одному упражнению, в каждом подходы с повторениями и весом, временем
  (с секундомером) или расстоянием, отдых между подходами с таймером, итоги и сохранение результата вместе с тренировкой (тренировка
  отмечается проведённой, результат виден в её карточке и на сайте). Незаконченную тренировку приложение хранит на устройстве и
  предлагает продолжить. Круговая тренировка идёт по часам: упражнение, отдых, круг за кругом (результаты она не записывает, как и на сайте).
- Статистика: у игрока — «Профиль → Моя статистика» (посещаемость кольцом, серия, задания, тренировочное время, рекорды, комментарии
  тренера, история матчей, показатели с добавлением, изменением и удалением своих записей, рекомендации ИИ); у тренерского состава —
  «Статистика» в карточке команды (показатели, задания, матчи, кому нужно внимание, три разбора ИИ) и статистика игрока по строке состава
  (тренер тоже может записать игроку показатель).
- Библиотека тренера (вкладка «Библиотека» у тренера; в панели вкладок телефона помещается пять, поэтому у тренера вместо «Тренеров»
  — каталог в «Профиль → Каталог тренеров»): упражнения (с фото), планы тренировок из упражнений по частям (разминка, основная, игровая, заминка; копия плана),
  шаблоны заданий. Упражнения и планы можно открыть командам: игроки читают их в карточке команды («Упражнения и планы»).
  Шаблон предлагается в форме нового задания; к заданию можно привязать план и упражнения из библиотеки.

- Состав команды (для тренерского состава): свайп влево по строке участника → «Ещё» (или долгое нажатие) открывает действия: назначить
  или снять капитана, назначить или снять помощника (только главный тренер), удалить из команды, заблокировать (только главный тренер).
  Удаление и блокировка спрашивают подтверждение; главный тренер и сам пользователь в списке без действий, помощников удаляет только
  главный тренер. Снять блокировку приложением нельзя (как и на сайте).
- Передача роли главного тренера (на экране команды, только главный тренер): выбрать участника, подтвердить в диалоге; прежний главный тренер остаётся помощником. Фразу подтверждения, которую сайт просит набрать вручную, приложение подставляет само

- Посещаемость: на проведённой тренировке команды у тренерского состава (и у ответственного игрока самостоятельной тренировки) —
  список игроков с переключателями «был / не был» (по умолчанию присутствуют все). Отметки видны в статистике, и по ним работает
  задание «Не были»: в форме задания выбирается проведённая тренировка (по дате, времени и месту), задание получают только отмеченные
  как отсутствовавшие.

- План для тренировки и брони: при назначении и изменении командной тренировки тренер выбирает один из своих планов («План тренировки»),
  и участники видят его в карточке тренировки и могут открыть. В «Профиль → Записи» у подтверждённой записи, которая ещё не проведена,
  тренер выбирает или снимает план (кнопка «Выбрать план тренировки»), а игрок видит его название.

- Видео: если задание просит видео, игрок выбирает его из медиатеки в форме сдачи; приложение само приводит ролик к 720p MP4
  (до 100 МБ), показывает длительность и размер и загружает его вместе со сдачей. Тренер и игрок открывают видео сдачи прямо в
  приложении. У упражнения тренер прикладывает видео в форме (не длиннее 60 секунд — как на сайте), оно загружается после
  сохранения и проигрывается в карточке упражнения. Ошибки сервера (слишком большой или длинный ролик, формат) показываются по-русски.

Ещё не сделано: универсальные ссылки и push-уведомления.

## Оформление

Внешний вид повторяет мобильную версию сайта (дизайн-система «MBA», `frontend/src/index.css`): тёплые нейтральные цвета и один красный,
тонкие границы, прямые углы, плоская нижняя панель с красной полоской над активной вкладкой, панели-«шапки» с волнистым орнаментом,
плитки-разделы, цветные полоски у событий календаря.

- Цвета, углы и шрифты — `App/Theme.swift` (те же токены, что на сайте, для светлой и тёмной темы). Орнамент, шапки, плитки,
  кнопки, логотип — `App/Views/Brand.swift`; нижняя панель — `App/Views/SagTabBar.swift`; оформление системных панелей — `App/Chrome.swift`.
- Тема: «Светлая / Тёмная / Как в системе» — переключатель на Главной и экране входа, выбор в «Профиль → Оформление»; выбор хранится на
  устройстве (`App/Appearance.swift`). Пока выбора нет, берётся тема системы.
- Проект назван на экране входа, в шапках и в блоке внизу Профиля (эмблема, название, версия); логотип — `Assets.xcassets/BrandLogo`.
- Шрифты сайта — Oswald (заголовки) и Montserrat (текст): вариативные TTF из `google/fonts` лежат в `App/Resources/Fonts` вместе с лицензией OFL
  и подключены через `UIAppFonts` в `project.yml`. Если файлов в сборке нет, `Theme.display/body` сами берут системные шрифты.
- Системную панель вкладок iOS 26 (плавающая «стеклянная» капсула) мы скрываем и рисуем свою, поэтому в UI-тестах панель ищется как
  `app.mainTabBar`, а не `app.tabBars`.
- Не использовать `containerBackground(for: .navigation)`: с поднятой клавиатурой в sheet приложение перестаёт быть «в покое» для
  XCUITest, и тесты ждут по минуте на каждое действие.

## Устройство

- `Sources/SportArenaKit` — всё, что не экран: клиент сервера (`APIClient`: cookie-сессия + `X-CSRF-Token`, разбор ошибок,
  даты ISO 8601, multipart), модели и сервисы. Собирается и тестируется без Xcode.
- `App/` — экраны и состояние (`@Observable`-сторы), `App/Views/` — SwiftUI-экраны.
- `Tests/SportArenaKitTests` — тесты на поддельном сервере (`MockServer`), без сети.
- `AppTests`, `AppUITests` — тесты приложения; UI-тесты ходят на **настоящий локальный сервер**.

## Как проверить

```bash
swift test                    # слой Kit, без Xcode и без сети
xcodegen generate             # проект Xcode собирается из project.yml (.xcodeproj в git не лежит)
```

UI-тестам нужен локальный сервер (адрес Debug-сборки — `http://localhost:8010`) с тестовыми аккаунтами. Логин и пароль
передаются только окружением, в репозитории их нет:

```bash
TEST_RUNNER_SAG_EMAIL=… TEST_RUNNER_SAG_PASSWORD=… \
  xcodebuild test -project SportArena.xcodeproj -scheme SportArena \
  -destination 'platform=iOS Simulator,name=iPhone 17' -parallel-testing-enabled NO
```

Часть тестов зависит от роли аккаунта (игрок или тренер) и от данных на сервере; если условий нет, тест пропускается, а не падает.
Для тестов приглашений дополнительно задаются `TEST_RUNNER_SAG_INVITE` (свежий токен приглашения) и `TEST_RUNNER_SAG_TEAM_NAME`.
Настоящие платежи в тестах не проводятся: оплата идёт через поддельную ЮKassa локального стенда.
