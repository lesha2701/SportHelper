# SportArena: Android-приложение (React Native + Expo)

Код приложения. Что нужно от backend, описано в `../docs/mobile.md`.

## Запуск

```bash
cd mobile
npm install
cp .env.example .env     # EXPO_PUBLIC_API_URL: адрес backend
npm run web              # проверка в браузере
npm start                # QR-код для Expo Go на телефоне
```

На телефоне `localhost` не работает: в `.env` укажите `http://<IP компьютера>:8002` (телефон и компьютер в одной Wi-Fi сети,
порт открыт в брандмауэре). В backend нужен `MOBILE_AUTH_ENABLED=true`, для веб-версии ещё `http://localhost:8081` в `CORS_ORIGINS`.

## Проверки

```bash
npm run typecheck
npm test
```

## Устройство

- `src/app/` — экраны (Expo Router): вход и регистрация, вкладки (главная, календарь, команды, задания, профиль),
  команда, тренировка, пошаговая тренировка, задание, матч, настройки.
- `src/api/` — запросы к backend (Bearer-токен из `expo-secure-store`, возврат на вход при 401).
- `src/shared/` — типы, разбор плана тренировки, даты, юридические документы; почти без изменений с сайта (`frontend/src`).
- `src/ui/` — компоненты (кнопка, поля, карточка, тосты, модальные окна), `src/theme/` — светлая и тёмная темы сайта.
- `src/workout/` — экран тренировки «на повторения» (подходы, вес, секундомер, дистанция, отдых, черновик на устройстве).

## Пока без

Заявки на вывод средств (создаются на сайте), перевод прав на команду, двухфакторная защита (только для администраторов, на сайте), push и App Links (в конце вместе с релизом). Платёж открывается во внешнем
браузере; кнопки оплаты и раздел «Финансы» видны, только если сервер включил платежи (`/api/features`). ИИ-функции работают, когда на сервере
настроен ключ Yandex AI Studio, иначе приложение показывает ответ сервера.
